# Источник и формат данных

## Происхождение

Набор данных — подвыборка стандартного датасета **MNIST** (рукописные цифры 0–9),
выданная преподавателем в рамках лабораторного практикума ИТМО. Используется
**вариант V3**. Данные не скачиваются из интернета: файлы предоставлены отдельно и
кладутся в `data/raw/` командой `make data` (в git не попадают, см. `.gitignore`).

Первоисточник: Попов И.Ю., Бучаев А.Я., Есипов Д.А. «Валидация систем
искусственного интеллекта: Лабораторный практикум». — СПб: Университет ИТМО,
2024. — 36 с.

## Формат (подтверждён кодом)

Проверка выполнена загрузчиком `mnist_validation.data.loading` и командой
`python -m mnist_validation check-data`:

- **Столбцы**: `label`, затем 784 столбца пикселей `1x1` … `28x28` (итого 785).
- **Тип пикселей**: целочисленный, значения в диапазоне **[0, 255]** (`uint8`).
- **Метки**: целые числа 0–9.
- **Пропуски (NaN)**: отсутствуют в обоих файлах.
- **Форма изображения**: вектор длины 784 = развёрнутая матрица 28 × 28.

## Известные проблемы качества (подтверждены кодом на этапе 0)

Эти факты обнаружены и перепроверены средствами пакета, а не приняты на веру:

- **Класс 3 раздут дубликатами**: 9997 объектов, из них **3866 полных дубликатов
  строк** (все дубликаты приходятся на класс 3).
- **Класс 9 урезан**: всего 2083 объекта — узкое место при балансировке.
- **Дубликаты изображений без учёта метки**: 3866 (совпадает с числом полных
  дубликатов строк, то есть повторов изображения с *другой* меткой нет).
- **Конфликтов меток** (одно изображение — разные метки): **0**.
- **Пересечение test↔train** по точным дубликатам изображений: **0** (утечки нет,
  тестовая выборка чистая).

Подробный анализ качества, поиск аномалий по статистикам и в пространстве
понижения размерности, а также построение сбалансированного и очищенного наборов
выполняются на этапе 1 (модуль `data/quality.py`, `data/cleaning.py`).
