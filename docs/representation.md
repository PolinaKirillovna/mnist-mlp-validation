# Представление изображений: вектор 784

## Как устроено преобразование

Каждое изображение MNIST — матрица 28 × 28 пикселей, значения 0–255 (оттенки
серого). В наборе данных оно хранится «развёрнутым» в вектор длины
784 = 28 · 28: строки матрицы последовательно записаны друг за другом
(row-major). Столбцы CSV названы `1x1` … `28x28`, где первое число — номер
строки, второе — номер столбца. Восстановление формы: `vector.reshape(28, 28)`.

Формально пиксель с координатами (r, c), r, c ∈ {0, …, 27}, попадает в позицию
вектора $i = 28 \cdot r + c$.

## Что сохраняется

- **Вся яркостная информация**: значения всех 784 пикселей присутствуют без
  потерь, преобразование обратимо (bijection между матрицей и вектором).
- **Возможность восстановить 2D-форму** в любой момент (`reshape`), что и
  используется при визуализации и в картах чувствительности.

## Что теряется (для полносвязной модели)

Само по себе разворачивание не теряет информацию, но **полносвязная сеть,
принимающая такой вектор, не использует пространственную структуру**:

- **Соседство пикселей**: для модели пиксели `1x1` и `1x2` (рядом по горизонтали)
  и `1x1` и `2x1` (рядом по вертикали) — просто разные координаты вектора.
  Отношение соседства (двумерная топология) в вектор не заложено; сеть должна
  «выучить» его из данных.
- **Инвариантность к сдвигу**: сдвиг цифры на один пиксель радикально меняет
  вектор признаков, хотя класс не меняется. Полносвязная модель не обладает
  встроенной инвариантностью к сдвигу, масштабу и небольшим поворотам (в отличие
  от свёрточных сетей).
- **Локальность**: свёртки выделяют локальные признаки (штрихи, углы) независимо
  от их положения; во входном векторе такой локальности нет.

## Практические ограничения

- Чувствительность к центрированию и сдвигам: модель, обученная на
  центрированных цифрах MNIST, будет хуже работать на смещённых.
- Число входных весов первого слоя пропорционально 784 · H, что для больших
  скрытых слоёв даёт много параметров без учёта пространственной регуляризации.
- Нормализация: перед подачей в сеть значения делятся на 255 (масштаб [0, 1]).
  Это влияет на интерпретацию знаков весов первого слоя (см. Часть 3): вход
  неотрицателен, поэтому положительный вес усиливает отклик там, где пиксель
  активен, а отрицательный — подавляет.
